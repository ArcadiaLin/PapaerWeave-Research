## 1 目的与定位

A3 是完整系统：写者经 PaperWeave 的 MCP 服务读写同一个库，各写者之间不协调。本次运行按冻结的任务表从种子建到 30 篇，在三个检查点留下库的快照与备份。

与 f2-A3 的区别在材料：f2 中每个写者从第一个会话起就能读、grep 全部 30 篇论文与代码；f3 中写者不挂载论文与代码，按材料表经来源服务 `read_source` 按 ID 取得，每个会话只能取任务点名的与此前已开放的来源。库因此更接近写者之间唯一的通道。

本次运行的快照与备份供以后：

- 读者在各检查点的备份上离线作答（写读分离），检验 H1 与 H2；
- 在快照上做库层审计；
- 给成本账本提供建库一侧的成本。

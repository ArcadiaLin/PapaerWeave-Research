### 1.2 各组的定义

- **C 闭卷组**：只给题目，不给论文、库和工具，量“不读材料能拿多少”[C §1]。
- **D 段落组**：不给库和工具，只给锚点处的原文段落与按题切行的主结果表，近似“检索完美”的上限参照 [D §1]。
- **P 原文组**：没有写者与库，读者在每个检查点用 pi 的默认工具直接读当时已入库论文的全文 [P §1]。
- **A3 完整系统**：写者经 PaperWeave 的 MCP 服务读写同一个库；f3 中写者经 `read_source` 只取任务点名的来源 [A3W §1]。f2-A3 是同一系统在“全材料可见”条件下的参照 [f2-A3W §1]。
- **A2 消融组**：与 A3 同一服务与工具说明，关掉查重、修订约束、过时标记、受影响产物四项机制 [A2W §1]。
- **A0 文件 + Git**：写者在共享 Git 仓库中按约定写 YAML 与 Markdown 并提交，没有 PaperWeave [A0W §1]。
- **A4 Graphiti**：写者经 Graphiti 官方 MCP 服务写 episode，由 Graphiti 内部 LLM 抽取实体与事实 [A4W §1]。
- **A3F 物化文件视图**：读 f3-A3 的同一库，在检查点导出为只读 Git 仓库，读者用 pi 默认工具读文件；导出是投影，省去提交 input 与 USED 边的 locators 等 [A3FR §1、§2.1]。

f3 与 f4 的读者（A3、A2、A0、A4、A3F）读原文都只经评测侧的 `read_evidence`，只交付库中记录过的锚点所在的块 [f3D §6]。

## 3 成本

### 3.1 口径与公式

- **原始量**：token 为各次模型调用之和；pi 的 input 不含命中缓存的部分（记为未缓存输入 $I_u$），缓存读另计（$C_r$），输出为 $O$（含思考；抽查的事件流中 `reasoning` 字段为 0）[A3R §4.1；补算抽查事件流]。模型调用是助手消息的条数，工具调用是助手消息中的工具调用条数 [A3R §4.1]。
- **总 token**：

  $$
  T = I_u + C_r + O
  $$

- **按计费加权的等价成本**（用户要求的新口径）：缓存读按折扣计，输出按倍数计，结果以“等价未缓存输入 token”表示：

  $$
  W_{\alpha,\beta} = I_u + \alpha\, C_r + \beta\, O
  $$

  主口径 $(\alpha, \beta) = (0.1, 5)$，即 $I_u : C_r : O = 1 : 0.1 : 5$，与 Anthropic 一类定价的比例相当；敏感性口径 $(\alpha, \beta) = (0.25, 4)$。
- **A4 的 Graphiti 内部 LLM**：只有 prompt $P_g$ 与 completion $Q_g$，没有缓存信息 [A4W §5]，本文把 prompt 全部按未缓存输入计：

  $$
  W^{\mathrm{A4}}_{\alpha,\beta} = I_u + \alpha\, C_r + \beta\, O + P_g + \beta\, Q_g
  $$

  表中 A4 分开列出“不含内部 LLM”与“含内部 LLM”两个值。
- **说明**：这只是相对的加权口径，不换算成金额，也不是任何服务商的实际账单。本实验用的是自部署的 Qwen 27B（sglang），没有实际计费；抽查的事件流中 `cost` 各项为 0，`cacheWrite` 也为 0，加权口径因此不含缓存写入的加价 [补算抽查事件流]。
- **用时**：各会话用时之和（不是墙钟）；墙钟另列。读者 4 路并发 [A3R §4.1]。
- 本节的 token 单位为 M（百万），保留两位小数；精确整数见各记录（A3F 读者见 3.3 节）。

## 对照组

- 〔已确认 2026-10-17〕**A0 文件 + Git，文字对等、机制不同：**
  - A0 拿到与 A3 对等的约定文档与模板：从 A3 的工具说明翻译而来，写明对象怎样分文件、字段与引用怎样写、产物有哪些类型及格式。schema 的文字相同，但没有任何执行：不查重、不校验引用、不记版本依赖、不提示过期。
  - 这改变了 V2 草案中“A0 不拿 schema”的约定（V2 草案 §2.2、§3.1）。理由：不给 A0 schema，A0 输了也说不清是输在机制还是输在不知道该怎么写；文字对等后，A0 与 A3 的差就是机制加上图层。
  - 打磨 A0 时只修指令失败：写者没看懂约定、格式写错这类改文字就能修的问题。机制失败只记录不修：漏掉重复、没发现过期、改了别人的内容不留理由、格式漂移、引用失效。只用文字与模板，不给 A0 脚本。
- 〔已确认 2026-10-17〕**保留 A2 同 schema 裸图：** 同一 Neo4j 与 schema，去掉查重、修订理由检查、`_stale` 与写入时提示。A2 与 A3 之差只来自机制。
- **消融（放在 E1 中，各去掉一项）：** 查重（身份候选）、写入时提示（`affected_artifacts` 与 `related_artifacts`）、读取时的过时标记（`_stale`）、共同编辑。
- **A4 Graphiti** 仍在计划中；需要新增依赖，先导阶段不做，待用户确认。

## 产物类型的覆盖

V3 实验室中 pi 实际写过、维护过的只有 Leaderboard。几个最可能拉开差距的机制落在其他类型上，所以工作负载要按意图覆盖各类产物：

- **CompareSettings（I3 可比性）：** 引用排行榜中的行，形成产物引用产物的链。排行榜更新后，引用它的比较能否被发现过期：A3 按所引版本判断并在提交时告诉写者，A0 的文件里只有引用文字。
- **Verify（I5）：** 两个写者在不同证据下核查同一条主张，结论相左。A3 把两种意见写在同一份 Verify 中、各带来源；看各组是否保住了两种意见，读者能否答出分歧。丢掉一种即计入知识流失。
- **Summarize（I2、I4）：** 没有身份键，两个写者写同一主题会得到两份。看读者能否找到并区分它们，以及所引的实验被修订后能否被发现过期。
- **Generate（I1、I6）：** 并入读者探针，不单独设计机制场景。
- **Skill：** 不进 E1。它是写者自己“怎么写”的知识，不是论文衍生的知识，放在讨论或附录中。

新类型先在 A3 上走通，只修指令失败，再上 A0、A2 与消融。

## 版本变化

论文换了新版本后，库里的锚点、数值与产物还指向旧版本。这一组测试看读者能否察觉、维护者能否改对，对应 E1 中的过期产物与悬空引用。

### 系统一侧的支持

- 写入时，Content 的 `FROM` 边与带锚点的边记下论文当时的材料（`material_ref`）。
- 论文换了新材料后，`get` 给出只读字段 `_anchor_version`：哪些锚点写在旧材料上、论文现在的材料、旧行的读法（`<旧材料 id>::<起>:<止>`）。改写锚点即换到新材料，提示随之消失（提交 `b1d9b1b`）。
- 产物的 `_stale` 给出 `superseded`（所用材料已有新版本）与 `material`（材料文件被改动）。
- 材料按内容哈希登记：内容相同的文件是同一个材料，只换文件名不算新版本。

### 测试材料

- 从语料中选一篇论文，伪造一个受控的 v2：变化的位置与内容完全已知，标准答案可以自动算出。
- 〔待定〕另配一篇真实的 v1 → v2 论文作对照，弥补伪造版本不自然的问题。

### 三种变化

- **行号移动：** 在表格前插入一段文字，内容不变、行号整体后移。
  - 读者：按记录的锚点引用原文，能否读对行（读旧材料，或察觉提示后改读新材料的对应行）。
  - 维护者：能否把锚点改写到新版本。
- **数值更正：** 改表中的一两个数，模拟勘误。
  - 读者：这个值现在是多少，变过没有。
  - 维护者：能否带理由修订相应记录；用到这些数值的排行榜能否给出 `superseded`，并由下一位写者更新。
- **内容删除：** v2 中去掉一张表或一条结论。
  - 读者：这条结论是否仍成立。
  - 维护者：能否删除记录或标为 `OPPOSES`，并留下理由。

### 对照与指标

- 对照组 files + Git：版本只是文件的更替，看读者能否发现引用的行已经不对。
- 指标：
  - 读者的答案是否正确；
  - 是否察觉到版本变化；
  - 维护后残留的错误锚点与错误数值。
- 〔待定〕每种变化各出几道题、伪造哪篇论文、是否与 E1 的写者规模变化一起跑。
